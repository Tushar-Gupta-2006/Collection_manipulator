# 📚 Student Data Organizer

A simple Python command-line application to manage student records using CRUD (Create, Read, Update, Delete) operations.

## ✨ Features
- Add a student
- Display all students
- Update student age or subjects
- Delete a student
- View all unique subjects offered
- Exit the program

## 🛠️ Technologies Used
- Python 3
- Dictionary, List, Tuple, Set

## ▶️ How to Run
```bash
python student_data_organizer.py
```

## 📌 Student Details
Each student record includes:
- Student ID
- Name
- Age
- Grade
- Date of Birth
- Subjects
